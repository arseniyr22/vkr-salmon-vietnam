## About this repository

This private repository documents the AI-assisted workflow used in preparing the thesis. It exists to satisfy the ВШЭ requirement for a detailed AI usage disclosure (НИС Кнатько, seminar 14–15, December 2025).

**What is here:**
- `AI_USAGE_LOG.md` — chronological log of every AI-assisted episode, structured per Knatko seminar requirements (section × purpose × tool × student actions × result)
- `ai_pipeline/` — saved prompts, raw AI outputs, and verified/edited versions
- `work/` — chapter outlines and subchapter drafts as they develop
- `reference/knatko_seminars/` — transcribed seminar materials used as the basis for disclosure format

**What is NOT here:**
- The final thesis text (submitted separately via LMS)
- Any confidential company data (none exists — Salmon analysis is based on public sources only)
- Internal process documents
