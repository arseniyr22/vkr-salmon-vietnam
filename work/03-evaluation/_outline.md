# Chapter 3: Evaluation — план главы

> Максимум 3-4 подглавы. Целевой объём 3500-5000 слов (12-17 страниц).
> Логика главы: «Сработает ли?» — оценка финансовой жизнеспособности и рисков.

---

## Зачем эта глава

Evaluation-глава отвечает на вопрос «Сработает ли?»:
1. Какие критерии оценки используются
2. Какова базовая финансовая логика выбранной стратегии
3. Какие риски и как они смягчаются
4. Какие условия должны выполниться, чтобы стратегия сработала

ВАЖНО — урок из прошлой версии:
- Прошлая глава 3 содержала NPV $78M, IRR 22%, 7 стресс-сценариев — это уровень McKinsey, не бакалавра
- Для ВКР подходит: unit economics, точка безубыточности, качественная оценка рисков, 1-2 сценария максимум
- Каждое допущение — с источником
- Честная фиксация ограничений данных

---

## План подглав (макс. 3-4)

### 1. Критерии оценки и метод (~700-1000 слов)
- Какие 3-5 критериев применяются (финансовая жизнеспособность, регуляторная допустимость, организационная готовность, временное окно)
- Какой метод для каждого критерия

### 2. Финансовая логика (~1200-1500 слов)
- Unit economics базовой стратегии (доход на одну единицу, переменные/постоянные затраты, точка безубыточности)
- Простая оценка размера рынка для Salmon
- 1 базовый сценарий, явно зафиксированные допущения
- _(NPV — только если Арсений может защитить устно каждую строку расчёта)_

### 3. Риск-профиль (~1000-1500 слов)
- 3-5 ключевых рисков (регуляторный, конкурентный, финансовый, операционный)
- Для каждого: источник, вероятность (high/medium/low), смягчение
- НЕ 7 стресс-сценариев

### 4. (опционально) Verdict и условия успеха (~600-1000 слов)
- При каких условиях стратегия работает
- Какие триггеры для пересмотра
- Связь с Conclusion
