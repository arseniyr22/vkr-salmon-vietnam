# ai_pipeline — рабочий пайплайн ИИ для ВКР

> Структура соответствует рекомендации Кнатько (НИС семинар 14-15, слайд 4) и обеспечивает выполнение требования «повторяемость» (слайд 11, п. 6).

## Что в каждой папке

### `prompts/`
Все значимые промпты, которые Арсений (или Claude от лица Арсения) формулировал при работе над ВКР. Каждый промпт — отдельный файл `.md` с именем `YYYY-MM-DD_<тема>.md`.

В начале каждого файла — frontmatter:
```
---
date: 2026-MM-DD
chapter: <раздел ВКР, к которому относится промпт>
purpose: <зачем — поиск/драфт/проверка/редактура>
output: ai_pipeline/raw_outputs/YYYY-MM-DD_<тема>.md
---
```

### `raw_outputs/`
Сырые ответы Claude до того, как Арсений их критически переработал. Имя файла зеркалит соответствующий промпт. Эти ответы **не идут напрямую в работу** — это вход для верификации.

### `verified/`
То, что прошло проверку Арсения и пошло в драфт подглавы. Если нужно — здесь же заметки о том, что было изменено по сравнению с raw output.

## Логика движения текста

```
ai_pipeline/prompts/    →    Claude    →    ai_pipeline/raw_outputs/
                                                       ↓
                                          (проверка Арсением вручную)
                                                       ↓
                                          ai_pipeline/verified/
                                                       ↓
                                              work/<глава>/<подглава>.md
```

## Что НЕ кладётся в эту папку

- Чаты целиком — слишком шумно. Только итоговый промпт + итоговый ответ.
- Ничего, что не используется в работе. Если эпизод оказался бесполезным — записываем в `AI_USAGE_LOG.md` пункт 5 («ошибки ИИ»), но raw output не сохраняем.
- Конфиденциальные данные. Для ВКР Salmon × Vietnam это не риск — данных компании нет, работаем с публичной информацией.

## Связь с журналом

Каждый эпизод в [AI_USAGE_LOG.md](../AI_USAGE_LOG.md) ссылается на конкретные файлы из этой папки. В финальном дисклеймере ссылки на `ai_pipeline/` пойдут как «промпты доступны по ссылке: …» (слайд 10 НИС Кнатько).
